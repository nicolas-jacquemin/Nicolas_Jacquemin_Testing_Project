*** Test Cases ***

# Positive Tests

Create Blank Project With Valid Name
    Navigate To Create Project Page ProjectUrl
    Select Blank Project Option
    Input Project Name Valid_ProjectName
    Submit Create Project Form
    Verify Page Should Contain Project 'FirstProject' was successfully created.

Create Project From Template
    Navigate To Create Project Page ProjectUrl
    Select Create From Template Option
    Choose Template Ruby on Rails
    Input Project Name Template_ProjectName
    Submit Create Project Form
    Verify Page Should Contain Project 'TemplateProject' was successfully created.

Update Name Of Existing Project
    Navigate To Project Settings Page Template_ProjectName
    Update Project Name Updated_ProjectName
    Save Settings
    Verify Page Should Contain Project was successfully updated.

Delete Project
    Navigate To Project Settings Page Updated_ProjectName
    Click Delete Project Button
    Confirm Deletion By Typing Project Name Updated_ProjectName
    Submit Delete Project Form
    Verify Page Should Contain Project 'UpdatedTemplateProject' is in the process of being deleted.

Validate Success Message After Creating Blank Project
    Navigate To Create Project Page ProjectUrl
    Select Blank Project Option
    Input Project Name Valid_ProjectName
    Submit Create Project Form
    Verify Page Should Contain Project 'FirstProject' was successfully created.


# Negative Tests

Create Blank Project With Duplicate Name
    Navigate To Create Project Page ProjectUrl
    Select Blank Project Option
    Input Project Name Duplicate_ProjectName
    Submit Create Project Form
    Verify Page Should Contain Name has already been taken

Create Blank Project With Empty Name
    Navigate To Create Project Page ProjectUrl
    Select Blank Project Option
    Input Project Name Empty
    Submit Create Project Form
