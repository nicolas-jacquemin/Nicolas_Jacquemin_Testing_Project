#******************** Test Cases *************************

*** Test Cases ***

# Positive Tests

Create Issue With Valid Title
    Navigate To New Issue Page IssueUrl
    Input Issue Title Valid_IssueTitle
    Submit Create Issue Form
    Verify Page Should Contain Issue 'First Issue' was successfully created.

Update Name Of Issue
    Navigate To Issue List Page ProjectSlug
    Open Issue Valid_IssueTitle
    Click Edit Issue Button
    Clear Issue Title Field
    Input Issue Title Updated_IssueTitle
    Save Issue Changes
    Verify Page Should Contain Issue saved.

Create Second Issue With Previously Updated Name
    Navigate To New Issue Page IssueUrl
    Input Issue Title Second_IssueTitle
    Submit Create Issue Form
    Verify Page Should Contain Issue 'Updated First Issue' was successfully created.

Delete First Issue
    Navigate To Issue List Page ProjectSlug
    Open Issue Updated_IssueTitle
    Click Edit Or Delete Icon
    Click Delete Issue Button
    Confirm Deletion
    Verify Page Should Contain Issue was deleted.


# Negative Tests

Create Issue With Empty Title
    Navigate To New Issue Page IssueUrl
    Input Issue Title Empty
    Submit Create Issue Form
    Verify That Error Message Should Show This field is required

Create Issue With Duplicate Title
    Navigate To New Issue Page IssueUrl
    Input Issue Title Duplicate_IssueTitle
    Submit Create Issue Form
    Verify Page Should Contain Issue 'Updated First Issue' was successfully created.
